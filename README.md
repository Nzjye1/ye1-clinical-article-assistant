# Ye1 临床文章助手

**你想完成一篇临床文章？从你现在的进度开始。**

告诉 Agent 你的目标，以及已有的研究方向、数据、结果、稿件或审稿意见。它会判断当前适合先做什么，结合实际可用的能力继续推进。

- 可以从研究想法、已有数据、文章草稿或返修意见进入。
- 复用已提供的材料，按当前任务衔接研究方案、分析、写作、检查或投稿等能力。
- 助手本身是轻量入口；其他 Skill 是否可用取决于当前 Agent 的实际环境。

试着说：“我有一批临床数据，想写一篇文章。先帮我看看现在适合从哪里开始。”

## 安装和使用

1. [下载完整 Skill ZIP](downloads/ye1-clinical-article-assistant-skill.zip)，解压后保留完整的 `ye1-clinical-article-assistant` 文件夹。也可以点击 Code → Download ZIP，解压后找到 `skills/ye1-clinical-article-assistant` 文件夹。
2. 在 WorkBuddy、Codex、Claude Code、Cursor 等支持 Skill 的 Agent 中新建任务，将完整文件夹交给 Agent 或按软件提示导入。
3. 安装后直接告诉 Agent 想完成的任务。不同软件的具体入口和权限以实际提示为准。

可复制：

> 请读取并安装这个 Skill 文件夹：这里填写完整文件夹路径。请按当前软件支持的方式操作，完成后告诉我如何开始使用。

部分任务需要联网、Python 或文档工具，Agent 会根据环境和权限准备。患者逐行资料应留在数据所在电脑，由本地工具处理；具体能力和限制请查看 [Skill 指引](skills/ye1-clinical-article-assistant/SKILL.md)。
